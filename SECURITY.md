# Security

This is a static, read-only website without user accounts or stored user data. If you find a security issue in this repository's code, please report it privately through [GitHub's private vulnerability reporting](https://github.com/rivalth/deu-web-remake/security/advisories/new) instead of opening a public issue.

Issues with Dokuz Eylül University's own websites are out of scope; please report those to the university.
